# ISTQB CTFL v4.0.1 Practice App

## Project Structure
```
ISTQB app/
├── GEMINI.md                  # This file
├── requirements.txt           # Python dependencies
├── package.json               # Node/Playwright dependencies
├── ingestion/
│   ├── scrape.py              # Downloads PDF files from ISTQB website
│   ├── build_db.py            # Parses seed data → populates data/istqb.db
│   └── export_static.py       # Exports data/istqb.db → frontend/data/db.json (for GitHub Pages)
├── seed/
│   ├── questions.json         # 40 official CTFL v4.0.1 Sample Exam A questions
│   ├── chapters.json          # Syllabus chapter structure
│   ├── glossary.json          # Key terms and definitions
│   └── theory_cards.json      # LO-based flashcards (K1/K2/K3)
├── data/
│   ├── raw/                   # Downloaded PDF files
│   └── istqb.db               # SQLite database (generated by build_db.py)
├── backend/
│   └── app.py                 # Flask API server
├── frontend/
│   ├── index.html             # Single-page application
│   ├── css/
│   │   └── style.css          # Responsive styles
│   └── js/
│       └── app.js             # Application state + API calls
└── tests/
    ├── quiz.spec.js           # Playwright UI tests (against Flask on :5050)
    ├── static.spec.js         # Playwright tests of the GitHub Pages build (static, no backend)
    └── static_server.py       # Serves frontend/ under /ISTQB_app/ on :5051 to mimic GitHub Pages
```

## Commands

### Setup
```bash
# Install Python deps
pip install flask flask-cors pdfplumber requests

# Install Node deps (Playwright)
npm install

# Build the database
python ingestion/build_db.py

# Start the server
python3 backend/app.py
# Access at http://localhost:5050 (configured to 5050 to avoid macOS AirPlay on port 5000)
```

### Run Tests
```bash
npx playwright test
```

### Full Reset & Rebuild
```bash
rm -f data/istqb.db && python ingestion/build_db.py
```

## Constraints
- No React, no webpack, no build step — pure vanilla HTML/CSS/JS
- SQLite only (no Postgres, no MongoDB)
- Backend: Python + Flask only
- Tests: Playwright (JavaScript/Node)
- Pass threshold: 65% (26/40 questions)
- Exam timer: 60 minutes

## API Endpoints
| Method | Path | Description |
|--------|------|-------------|
| GET | /api/chapters | List all chapters |
| GET | /api/chapters/<id> | Get chapter with glossary & math types |
| GET | /api/questions | All questions (optional ?chapter=) |
| GET | /api/theory-cards | All theory cards (optional ?chapter=&k_level=) |
| GET | /api/math-types | All math types (optional ?chapter=) |

## Database Schema
```sql
chapters   (id, number, title, content)
glossary   (id, term, definition, chapter_id)
questions  (id, chapter_id, stem, explanation, difficulty)
options    (id, question_id, label, text, is_correct)
theory_cards (id, chapter_id, lo_reference, k_level, front_text, back_text)
math_types (id, chapter_id, title, simple_rule, formula, example, tip)
```
